# שיבוצון

אפליקציית ווב לניהול ושיבוץ בודקים בעמדות שער יציאה — עם MongoDB Atlas.

## הרצה

1. העתיקו `.env.example` ל-`.env` והדביקו את מחרוזת החיבור ל-MongoDB.
2. התקינו והריצו:

```bash
npm install
npm run dev
```

זה מריץ במקביל:
- API על `http://127.0.0.1:3001`
- Frontend על `http://127.0.0.1:5173` (עם proxy ל-`/api`)

נדרש Node.js 20+.

## אבטחה

אל תשתפו את קובץ `.env` ואל תעלו אותו ל-Git. אם הסיסמה נחשפה — החליפו אותה ב-Atlas.
